# Plan: Create Subfolders from Sidebar

## Overview
Add a "+" button next to each folder in the left sidebar that opens a modal dialog for creating a new subfolder.

## Files to Modify
- `src/popup/App.svelte` — add modal state, UI, and folder creation logic

## Implementation Details

### 1. New State Variables
- `showCreateModal: boolean` — controls modal visibility
- `createModalParentId: string | null` — ID of the parent folder
- `newFolderName: string` — value of the input field

### 2. New Functions
- `openCreateModal(folderId: string)` — opens modal with parent folder ID
- `closeCreateModal()` — closes modal and resets state
- `handleCreateFolder()` — validates input, calls `chrome.bookmarks.create()`, refreshes tree, expands parent folder

### 3. UI Changes
- **"+" button** — added to the right side of each folder row in the sidebar, visible on hover (group-hover)
- **Modal overlay** — semi-transparent backdrop covering the popup
- **Modal content** — centered box with:
  - Title: "New Folder"
  - Text input: bound to `newFolderName`
  - OK button: triggers `handleCreateFolder()`
  - Cancel button: triggers `closeCreateModal()`

### 4. Folder Creation Logic
```typescript
async function handleCreateFolder() {
    if (!newFolderName.trim() || !createModalParentId) return;
    try {
        await chrome.bookmarks.create({
            parentId: createModalParentId,
            title: newFolderName.trim()
        });
        // Refresh tree
        const entireTree = await chrome.bookmarks.getTree();
        folderTree = processTree(entireTree);
        // Expand the parent folder to show the new subfolder
        expandedFolders.add(createModalParentId);
        closeCreateModal();
    } catch (err) {
        console.error('Failed to create folder:', err);
    }
}
```

### 5. Events
- Modal backdrop click → `closeCreateModal()`
- OK button click → `stopPropagation`, then `handleCreateFolder()`
- Cancel button click → `stopPropagation`, then `closeCreateModal()`
- Escape key → `closeCreateModal()`
- Plus button click → `stopPropagation`, then `openCreateModal(folderId)`
