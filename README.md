# Bookmark Search & Path: Simple Viewer

A plain, lightweight, and fast browser extension that helps you instantly locate your saved links and view their full folder hierarchies directly below the URL.

---

## ⚡ Why This Extension?

Most built-in bookmark managers are heavy and don't show you where your found links are actually stored. This plain extension operates entirely in your side panel, displaying the exact folder path for every single search result with zero lag.

## 🚀 Features

*   **Fast Search:** Real-time filtering across thousands of bookmarks.
*   **Plain View:** Hierarchical folder paths are displayed right below the link.
*   **One-Click Navigation:** Preview and open folders or links instantly.
*   **Privacy First:** Operates 100% locally within your browser context. No data collection.

## 🛠️ Tech Stack & Architecture

*   **Framework:** Svelte 5 (or modern declarative UI)
*   **Manifest Version:** 3
*   **Storage:** Local Chrome Bookmarks API

## 📦 How to Run Locally (Development)

1. Clone this repository.
2. Run `npm install` and `npm run build` (if using a bundler).
3. Open Chrome and navigate to `chrome://extensions/`.
4. Enable **Developer mode** (top-right toggle).
5. Click **Load unpacked** and select the build/dist folder.
